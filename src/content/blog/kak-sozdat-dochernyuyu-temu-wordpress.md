Если вы когда-нибудь правили код чужой темы WordPress и чувствовали лёгкое напряжение перед нажатием «Обновить», вы не один. Тема обновляется, файлы заменяются, и **чем больше вы кастомизировали — тем больше риск потерять всё**. Именно для этой задачи в WordPress есть **дочерние темы**.

Разберёмся, что это, зачем нужно и как создать дочернюю тему правильно — по шагам.

## Что такое дочерняя тема

**Дочерняя тема** — это отдельная тема, которая **наследует всё** от другой темы — **родительской**. Родитель содержит шаблоны, стили, функции и всю основу. Дочерняя берёт это как базу и позволяет добавлять свои правки, **не трогая файлы родителя**.

WordPress сначала ищет файл в дочерней теме. Если находит — использует его. Если нет — берёт из родительской. Это значит:

- Вы можете **переопределить** отдельные файлы (например, `header.php`)
- Можете **добавить свой CSS** в `style.css`
- Можете **дописать функции** через `functions.php`
- **Всё остальное продолжает работать из родительской темы** автоматически

Когда родительская тема обновляется — ваши правки не пропадают, потому что они лежат **в отдельной папке**.

## Зачем использовать дочернюю тему

Три главные причины.

### 1. Правки выживают при обновлениях

Если редактировать файлы родительской темы напрямую — при обновлении они **затрутся**. С дочерней темой ваши изменения лежат отдельно, и обновления родителя их не касаются.

### 2. Легко откатить

Сломали что-то в дочерней теме? Удалите проблемный файл или папку целиком — сайт вернётся к поведению родительской темы. Это работает как **встроенная страховка**.

### 3. Быстрее разработка

Дочерняя тема **переиспользует** шаблоны, функции и стили родителя. Не нужно писать с нуля — вы работаете только с теми частями, которые действительно нужно изменить.

## Что нужно подготовить

- **Работающий WordPress** с установленной родительской темой
- **Доступ к файлам сайта** — FTP, SFTP или файловый менеджер хостинга (cPanel, ISPmanager и т.п.)
- **Имя папки родительской темы** — оно понадобится в заголовке дочерней. Не отображаемое название, а **имя папки** внутри `wp-content/themes/`

**Как узнать имя папки родителя:** откройте `wp-content/themes/` в файловом менеджере и посмотрите, как называется папка темы. Например, `twentytwentyfour` или `astra`.

## Пошаговая инструкция: создаём дочернюю тему

### Шаг 1. Создайте папку для дочерней темы

Зайдите в `/wp-content/themes/` и создайте новую папку. **Название должно быть понятным** — обычно к имени родителя добавляют `-child`:

```
wp-content/themes/twentytwentyfour-child/
```

Если родительская тема в папке `astra`, дочерняя пусть будет `astra-child`.


### Шаг 2. Создайте style.css с заголовком

Внутри папки дочерней темы создайте файл **`style.css`**. Это **не CSS** — сначала идёт **заголовок-комментарий**, по которому WordPress распознаёт тему:

```css
/*
Theme Name:   Twenty Twenty-Four Child
Theme URI:    https://example.com/twentytwentyfour-child/
Description:  Дочерняя тема для Twenty Twenty-Four
Author:       Ваше имя
Author URI:   https://example.com/
Template:     twentytwentyfour
Version:      1.0.0
Text Domain:  twentytwentyfour-child
*/

/* Ваши стили ниже */
```

**Самая критичная строка — `Template:`.** Она должна **точно совпадать с именем папки** родительской темы, а не с её отображаемым названием. Если папка родителя называется `astra`, то `Template: astra`. Ошибка здесь — **причина №1**, по которой тема не появляется в админке.


### Шаг 3. Создайте functions.php

В той же папке создайте файл **`functions.php`** — он правильно подключит стили родительской и дочерней темы:

```php
<?php
add_action( 'wp_enqueue_scripts', 'my_child_theme_styles' );
function my_child_theme_styles() {
    // Сначала стили родительской темы
    wp_enqueue_style(
        'parent-style',
        get_template_directory_uri() . '/style.css'
    );

    // Потом стили дочерней, с зависимостью от родителя
    wp_enqueue_style(
        'child-style',
        get_stylesheet_uri(),
        array( 'parent-style' ),
        wp_get_theme()->get( 'Version' )
    );
}
```

**Что важно:**

- **`get_template_directory_uri()`** возвращает путь к **родительской** теме
- **`get_stylesheet_uri()`** возвращает путь к `style.css` **дочерней** темы
- **`array( 'parent-style' )`** гарантирует, что стили дочерней загрузятся **после** родительской — иначе ваши правки не перекроют базовые

### Шаг 4. Активируйте тему

Зайдите в **Внешний вид → Темы** в админке. В списке появится ваша дочерняя тема — нажмите **«Активировать»**.


Если всё сделано правильно — сайт будет выглядеть **так же, как на родительской теме**. Это ожидаемо: вы наследуете все стили родителя. Теперь можно кастомизировать безопасно.

## Как кастомизировать дочернюю тему

После активации у вас два основных инструмента: **CSS-переопределения** и **переопределения шаблонов**.

### CSS-переопределения

Любой CSS, добавленный в `style.css` дочерней темы, **перекрывает** родительский — при условии, что селектор достаточно специфичен, а стили загружаются после родительских.

**Пример.** Родительская тема задаёт ссылки:

```css
a { color: #0073aa; }
```

В дочерней теме переопределяем:

```css
a { color: #d54e21; }
```

Сохраняем, обновляем сайт — цвет ссылок изменился.

**Если изменения не видны** — сбросьте кэш браузера (`Ctrl+F5`), кэш плагина или кэш хостинга.

### Переопределение шаблонов

Чтобы изменить конкретный файл темы (например, `header.php`):

1. **Найдите файл** в родительской теме: `/wp-content/themes/parent-theme/header.php`
2. **Скопируйте** его в дочернюю: `/wp-content/themes/parent-theme-child/header.php`
3. **Отредактируйте копию**

WordPress автоматически подхватит файл из дочерней темы вместо родительского. Всё, что вы не переопределили, продолжит загружаться из родителя.

**Не копируйте все файлы подряд.** Берите только те, что **реально нужно менять** — иначе дочерняя тема раздувается, а преимущество наследования обновлений теряется.

## Частые ошибки

**1. `Template:` не совпадает с именем папки родителя.** Тема не появляется в списке доступных. Проверьте, что значение совпадает **буква в букву**, включая регистр.

**2. Забыли подключить стили родителя.** Вёрстка «разваливается», потому что родительский `style.css` не загружен. В `functions.php` дочерней темы обязательно должен быть `wp_enqueue_style( 'parent-style', ... )`.

**3. Использовали `@import`.** Устаревший метод, замедляет загрузку. Замените на `wp_enqueue_style()`.

**4. Использовали `get_template_directory_uri()` для файлов дочерней темы.** Эта функция ведёт в **родительскую** папку. Для дочерних файлов — `get_stylesheet_uri()` и `get_stylesheet_directory_uri()`.

**5. Скопировали все файлы «на всякий случай».** Это сводит на нет все преимущества дочерней темы. Копируйте только то, что действительно нужно менять.

## FAQ

### Почему моя дочерняя тема не работает?

Обычно одна из причин:

- `Template:` в `style.css` не совпадает с именем папки родителя
- Папка дочерней темы лежит не в `wp-content/themes/`
- В `style.css` нет заголовка-комментария
- `functions.php` не подключает стили родителя
- Включён кэш — попробуйте сбросить

### Можно ли создать «внучку» — дочернюю от дочерней?

Стандартно — **нет**. WordPress поддерживает только одну связь «родитель → ребёнок» через `Template:`. Дочерняя тема не может иметь свою дочернюю. Если нужно больше уровней — лучше консолидировать правки в одну дочернюю тему или сделать новую на основе исходного родителя.

### Нужна ли дочерняя тема, если я правлю только CSS?

Не всегда. Для маленьких правок хватит **«Дополнительные стили»** в кастомайзере — они не сбрасываются при обновлении темы. Но если вы планируете долгую работу, версионирование, отдельную среду разработки или переносимость настроек — **дочерняя тема чище в долгосрочной перспективе**.

### Что если родительская тема — блочная (например, Twenty Twenty-Five)?

Для блочных тем обычные плагины-генераторы могут **не скопировать все настройки** из редактора блоков. В этом случае используйте официальный плагин **Create Block Theme** от WordPress:

1. Установите плагин
2. Перейдите в **«Внешний вид → Create Block Theme»**
3. Нажмите **«Create a Child of Parent Theme»**
4. Плагин скопирует все настройки из редактора блоков
5. Активируйте тему, проверьте результат, удалите плагин

## Итог

Дочерняя тема — это **страховка** для дизайна и функционала сайта. Вы получаете и обновления от родительской темы, и безопасное место для своих правок.

**Минимальный набор файлов для создания:**

- [ ] Папка в `wp-content/themes/`
- [ ] `style.css` с заголовком и обязательным полем `Template:`
- [ ] `functions.php` с `wp_enqueue_style()` для стилей родителя и дочерней

**Три ключевых правила:**

1. **Никогда не правьте родительскую тему напрямую**
2. **Копируйте только те файлы, что действительно нужно менять**
3. **Подключайте стили через `functions.php`, а не через `@import`**
