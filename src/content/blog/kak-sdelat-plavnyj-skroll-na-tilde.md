Плавный скролл — это функция, которая делает прокрутку страницы более мягкой и приятной для восприятия. Вместо резких рывков при вращении колёсика мыши пользователь видит плавное перемещение по контенту. Такой эффект заметно улучшает пользовательский опыт и делает навигацию по лендингу более комфортной.

В этой статье мы разберём, как сделать плавный скролл на Тильде с помощью простого встраивания кода — без плагинов и сложных настроек. Инструкция подойдёт даже новичкам.

## Что понадобится

Для реализации плавного скролла на Тильде используется библиотека **SmoothScroll (v1.4.10)**. Это лёгкое решение с открытым исходным кодом:

- **Автор:** Alice Lieutier
- **Лицензия:** MIT (разрешено коммерческое использование)
- **Репозиторий:** [github.com/alicelieutier/smoothScroll](https://github.com/alicelieutier/smoothScroll)
- **Назначение:** реализует плавную анимацию прокрутки на веб-странице

## Пошаговая инструкция: как сделать плавный скролл на Тильде

### Шаг 1. Добавьте блок T123

Откройте нужную страницу в редакторе Tilda. Нажмите **«Добавить блок»** → выберите категорию **«Другое»** → **«HTML-код»** (T123).

![Меню добавления блока T123 в редакторе Tilda](/images/blog/kak-sdelat-plavnyj-skroll-na-tilde-01.png)

### Шаг 2. Вставьте код плавного скролла

Скопируйте приведённый ниже код и вставьте его в блок T123:

```html
<script 
  src="https://cdnjs.cloudflare.com/ajax/libs/smoothscroll/1.4.10/SmoothScroll.min.js" 
  integrity="sha512-HaoDYc3PGduguBWOSToNc0AWGHBi2Y432Ssp3wNIdlOzrunCtB2qq6FrhtPbo+PlbvRbyi86dr5VQx61eg/daQ==" 
  crossorigin="anonymous"
></script>

<script>
  // Настройки плавного скролла
  SmoothScroll({
    animationTime: 900,       // Длительность анимации (мс)
    stepSize: 70,             // Размер шага скролла (пиксели)
    touchpadSupport: true,    // Поддержка тачпадов
    accelerationDelta: 20,    // Чувствительность к ускорению
    accelerationMax: 2,       // Максимальное ускорение
    pulseAlgorithm: true,     // Использовать "пульсирующий" алгоритм
    pulseScale: 4,            // Масштаб пульсации
    pulseNormalize: 1,        // Нормализация пульсации
    keyboardSupport: true,    // Поддержка клавиатуры
    arrowScroll: 75           // Скролл стрелками (пиксели)
  });
</script>
```

![Блок T123 с вставленным кодом SmoothScroll](/images/blog/kak-sdelat-plavnyj-skroll-na-tilde-02.png)

### Шаг 3. Настройте параметры под свой сайт

Если стандартные значения вам не подходят, измените их в блоке `SmoothScroll({...})`:

- **`animationTime`** — длительность анимации прокрутки в миллисекундах
- **`stepSize`** — размер шага скролла
- **`touchpadSupport`** — поддержка тачпадов
- **`accelerationDelta`** / **`accelerationMax`** — чувствительность и максимум ускорения
- **`pulseAlgorithm`** / **`pulseScale`** / **`pulseNormalize`** — настройки «пульсирующего» алгоритма
- **`keyboardSupport`** — поддержка управления с клавиатуры
- **`arrowScroll`** — величина прокрутки стрелками

### Шаг 4. Сохраните и проверьте результат

Опубликуйте страницу и проверьте, как работает плавный скролл в режиме предпросмотра и на живом сайте. При необходимости скорректируйте параметры.

## Итог

Теперь вы знаете, как сделать плавный скролл на Тильде всего за несколько минут: добавить блок T123, вставить скрипт SmoothScroll и при желании настроить параметры анимации. Это простой, бесплатный и безопасный способ повысить удобство сайта.
