DOM — это аббревиатура от **Document Object Model**, что переводится как «объектная модель документа».

Но если вы просто заучите это название, вы ничего не поймёте. Запомнить нужно вот это:

**DOM — это дерево объектов, в которое браузер превращает HTML-документ, чтобы JavaScript мог с ним работать.**

HTML, который вы пишете, — это статичный текст, понятный браузеру. Но JavaScript не понимает HTML-теги. Он понимает только объекты. Поэтому браузер при загрузке страницы автоматически разбирает HTML и строит из него древовидную структуру из объектов. Через неё JavaScript может читать, изменять, добавлять и удалять что угодно на странице. Эта структура и есть DOM.

## Зачем нужен DOM

Без DOM JavaScript был бы полностью бессилен перед веб-страницей.

Что написано в HTML — то и отображается. Пользователь нажимает кнопку, отправляет форму, вводит текст — ничего из этого не работает. Страница «мёртвая».

DOM решает эту проблему. Он служит **мостом между JavaScript и HTML**. JavaScript через DOM получает доступ к странице и управляет ею:

- получает содержимое нужного элемента
- меняет текст, стили, атрибуты
- создаёт новые элементы и вставляет их на страницу
- удаляет существующие элементы
- отслеживает клики, ввод и другие события пользователя

Поэтому фраза «работа с DOM через JS» на самом деле означает **изменение HTML-документа через интерфейс DOM с помощью JavaScript**.

## Древовидная структура DOM

Сам HTML-документ имеет иерархию. Внутри `<html>` лежат `<head>` и `<body>`, внутри `<body>` — другие элементы. DOM отображает эту иерархию в виде дерева.

Возьмём простейший HTML:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Заголовок</h1>
    <p>Абзац текста</p>
  </body>
</html>
```

Дерево DOM, которое построит браузер, выглядит так:

```text
document
  └── html
        ├── head
        │     └── title
        │           └── #text "Моя страница"
        └── body
              ├── h1
              │     └── #text "Заголовок"
              └── p
                    └── #text "Абзац текста"
```


Каждый элемент в дереве называется **узлом (Node)**.

### Типы узлов

Узлы бывают разных типов:

- **Элементные узлы** — соответствуют HTML-тегам: `<html>`, `<body>`, `<h1>`, `<p>`
- **Текстовые узлы** — текст внутри тегов: «Заголовок», «Абзац текста»
- **Узлы комментариев** — HTML-комментарии `<!-- -->`
- **Узлы атрибутов** — атрибуты элементов: `class="btn"`, `id="main"`

![Четыре типа узлов DOM](/images/blog/chto-takoe-dom-02.png)

На вершине дерева стоит объект `document`. Это точка входа во весь DOM. Через него JavaScript получает доступ ко всему, что есть на странице.

## Отношения между узлами

Чтобы понимать DOM, нужно освоить несколько терминов, описывающих связи между узлами. Они перекликаются с понятиями из CSS-селекторов.

Рассмотрим `<body><h1>Заголовок</h1><p>Текст</p></body>`:

| Термин | Значение | Пример |
|---|---|---|
| **Корневой узел** | Самый верхний узел дерева | `document` или `html` |
| **Родительский узел** | Узел, который напрямую содержит другой узел | `body` — родитель для `h1` и `p` |
| **Дочерний узел** | Узел, который напрямую содержится в другом | `h1` и `p` — дочерние для `body` |
| **Сестринский узел** | Узлы на одном уровне с общим родителем | `h1` и `p` — сестринские узлы |
| **Узел-потомок** | Любой узел на любом уровне вложенности | `h1` — потомок `body` и потомок `html` |

Эти термины вы будете постоянно встречать при написании JavaScript и CSS-селекторов. Их стоит запомнить сразу.

## DOM — это не часть JavaScript

Это самый частый источник путаницы у новичков, и его нужно прояснить:

**DOM — не языковая особенность JavaScript, это отдельный Web API.**

- JavaScript может работать **без DOM**. Например, Node.js использует JavaScript для серверного кода, но DOM там нет — на сервере просто нет веб-страницы.
- DOM спроектирован **независимо от какого-либо языка программирования**. Теоретически Python или Java тоже могли бы работать с DOM. Просто в реальной браузерной разработке почти все работают с DOM через JavaScript.

Поэтому точнее говорить так:

**Браузер предоставляет DOM API, а JavaScript вызывает этот API для управления веб-страницей.**

## Пример работы с DOM через JavaScript

Теория без практики бесполезна. Допустим, на странице есть такая ссылка:

```html
<a href="https://example.com">Нажми меня</a>
```

Меняем её текст и адрес через JavaScript и DOM:

```javascript
// Шаг 1: выбираем элемент
const link = document.querySelector("a");

// Шаг 2: меняем текст
link.textContent = "Новый текст";

// Шаг 3: меняем адрес ссылки
link.href = "https://new-url.com";
```

Три строки — и ссылка, которая показывала «Нажми меня», теперь показывает «Новый текст» и ведёт на новый адрес.


**`document.querySelector("a")`** — самый часто используемый метод выбора элемента. Он принимает CSS-селектор и возвращает **первый подходящий** элемент в документе.

Если нужно выбрать **все** подходящие элементы, используют `document.querySelectorAll()` — он возвращает `NodeList`, коллекцию узлов. Она похожа на массив, но это не массив: у неё нет методов `map`, `filter`, `reduce`. Чтобы работать с ней как с массивом, её преобразуют через `Array.from()` или спред-оператор.

## Итог

Соберём главное:

1. **DOM — это дерево объектов, в которое браузер превращает HTML-документ**, чтобы JavaScript мог управлять страницей.
2. **DOM — не часть JavaScript**, это отдельный Web API.
3. **Дерево DOM состоит из узлов**, у узлов есть типы (элемент, текст, комментарий и другие) и отношения родитель-ребёнок-сестра.
4. **Объект `document` — точка входа в DOM**, через него JavaScript находит элементы и работает с ними.
5. **Самые популярные методы выбора элемента — `document.querySelector()` и `document.querySelectorAll()`**.

Поняв эти пять пунктов, вы поймёте, что такое DOM и почему это базовая концепция, без которой не обходится фронтенд-разработка.
