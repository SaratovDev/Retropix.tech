Flexbox (гибкая вёрстка) — это инструмент в CSS, созданный для решения задач **одномерной вёрстки**. Одномерной — значит, он работает с одним направлением за раз: либо строка, либо колонка. Этим он отличается от Grid, который двумерный и управляет строками и колонками одновременно.

Вам **не нужно запоминать все 12 свойств**. 90% реальных задач решаются четырьмя свойствами. Ниже — базовые концепции, обязательные свойства и готовые шаблоны, которые можно сразу копировать в проект.

## Две главные оси: основная и поперечная

Ключ к пониманию Flexbox — это понимание **главной оси (main axis)** и **поперечной оси (cross axis)**.

- **Главная ось** — направление, в котором выстраиваются flex-элементы. По умолчанию — горизонтально (слева направо). Управляется свойством `flex-direction`.
- **Поперечная ось** — перпендикулярна главной. Если главная ось горизонтальна, поперечная — вертикальна.

![Схема главной и поперечной осей Flexbox](/images/blog/chto-takoe-flexbox-i-kak-ego-ispolzovat-01.png)

Все свойства Flexbox работают вокруг этих двух осей. Запомните это — и дальше ничего не придётся заучивать: свойства на `justify-` управляют **главной** осью, на `align-` — **поперечной**.

## Шаг 1: включаем Flexbox

Пишем одну строку CSS на родительском элементе (контейнере):

```css
.container {
  display: flex;
}
```

Только от этой строки все прямые дочерние элементы контейнера **выстроятся в горизонтальный ряд** слева направо, а их высота растянется до высоты контейнера. Это исходное поведение Flexbox.

Если нужно, чтобы сам контейнер был строчным элементом (ширина по содержимому), используйте `display: inline-flex`.

## Свойство 1: flex-direction (направление)

Значение по умолчанию `row` выстраивает элементы слева направо. Меняем на `column` — и они идут сверху вниз.

```css
.container {
  display: flex;
  flex-direction: column; /* элементы встают вертикально */
}
```

Ещё два значения — `row-reverse` и `column-reverse` — разворачивают порядок.

## Свойство 2: justify-content (главная ось)

Управляет расположением элементов **вдоль главной оси**. Три самых нужных значения:

```css
/* Всё прижато влево (по умолчанию) */
justify-content: flex-start;

/* Всё по центру — самый классический приём Flexbox */
justify-content: center;

/* Крайние элементы по краям, между ними — равные промежутки */
justify-content: space-between;
```

Другие значения: `flex-end` (вправо), `space-around` (у каждого элемента равные отступы слева и справа), `space-evenly` (все промежутки абсолютно равны).

![Шесть вариантов justify-content](/images/blog/chto-takoe-flexbox-i-kak-ego-ispolzovat-03.png)

## Свойство 3: align-items (поперечная ось)

Управляет выравниванием элементов **по поперечной оси**.

```css
/* По умолчанию: растягиваются на всю высоту контейнера */
align-items: stretch;

/* Вертикальное центрирование — в паре с justify-content: center даёт «идеальный центр» */
align-items: center;

/* Прижаты к верху */
align-items: flex-start;
```

**Это главное преимущество Flexbox перед старыми способами вёрстки.** Чтобы отцентрировать div по вертикали внутри контейнера, раньше приходилось изобретать костыли с `position: absolute` и `transform`. Теперь хватает двух строк.

![Три варианта align-items](/images/blog/chto-takoe-flexbox-i-kak-ego-ispolzovat-04.png)

## Свойство 4: flex-wrap (что делать, если не влезает)

По умолчанию flex-элементы **не переносятся на новую строку**. Если контейнер не вмещает все элементы, они сжимаются и деформируются.

```css
.container {
  flex-wrap: wrap; /* не влезло — переносим на следующую строку */
}
```

Для адаптивных карточных сеток `flex-wrap: wrap` — почти обязательный пункт.

![flex-wrap: без переноса и с переносом](/images/blog/chto-takoe-flexbox-i-kak-ego-ispolzovat-05.png)

## Свойство для дочерних элементов: flex

Свойство `flex`, написанное на **дочернем элементе**, управляет тем, как элемент распределяет свободное пространство. Это сокращённая запись, самая частая форма:

```css
.item {
  flex: 1;
}
```

**Смысл:** `flex: 1` равно `flex-grow: 1` + `flex-shrink: 1` + `flex-basis: 0%`. Результат — каждый элемент **поровну делит всё пространство контейнера**.

```css
/* Три элемента с соотношением ширины 1:1:2 */
.item:nth-child(1) { flex: 1; }
.item:nth-child(2) { flex: 1; }
.item:nth-child(3) { flex: 2; }
```

Третий элемент займёт две доли, первые два — по одной. Всего 4 доли: третий получит 2/4 (половину), первые — по 1/4.

## Где писать свойства: таблица

Одна из самых частых причин ошибок — свойства пишут не на том элементе. Запомните:

| Свойство | Где писать | Что делает |
|---|---|---|
| `display: flex` | **На родителе** | Включает flex-контейнер |
| `flex-direction` | **На родителе** | Направление главной оси |
| `justify-content` | **На родителе** | Выравнивание по главной оси |
| `align-items` | **На родителе** | Выравнивание по поперечной оси |
| `flex-wrap` | **На родителе** | Разрешает перенос строк |
| `gap` | **На родителе** | Отступы между элементами |
| `flex` | **На дочернем** | Как элемент делит пространство |
| `align-self` | **На дочернем** | Переопределяет `align-items` для одного элемента |
| `order` | **На дочернем** | Меняет порядок отображения |

## Три шаблона для реальных задач

### Шаблон 1: Навигация (логотип слева, меню справа)

```css
.navbar {
  display: flex;
  justify-content: space-between; /* раздвигаем по краям */
  align-items: center; /* выравниваем по вертикали */
}
```

### Шаблон 2: Карточка идеально по центру контейнера

```css
.card-container {
  display: flex;
  justify-content: center; /* по горизонтали */
  align-items: center; /* по вертикали */
  min-height: 300px;
}
```

Эти две строки заменяют то, что раньше требовало `position: absolute` + `transform`.

### Шаблон 3: Адаптивная карточная сетка

```css
.cards {
  display: flex;
  flex-wrap: wrap; /* не влезло — переносим */
  gap: 16px; /* отступы между элементами */
}

.card {
  flex: 1 1 250px; /* минимальная ширина 250px, растягивается при наличии места */
}
```

`flex: 1 1 250px` означает: стартовая ширина 250px, есть свободное место — тянемся, не хватает — сжимаемся. Когда три карточки в строку не помещаются, они автоматически переносятся на две строки.

## Три самые частые ошибки новичков

**Ошибка 1: забыли `display: flex`.** Все свойства Flexbox не работают, потому что контейнер так и не стал flex-контейнером.

**Ошибка 2: путают `justify-content` и `align-items`.** Запомните: `justify` — главная ось (по умолчанию горизонталь), `align` — поперечная (по умолчанию вертикаль). Если поменяли `flex-direction: column`, оси меняются ролями.

**Ошибка 3: пишут свойства не на том элементе.** `justify-content`, `align-items`, `flex-wrap` — на родителе. `flex`, `order`, `align-self` — на дочерних элементах.

## Итог

Flexbox не требует заучивания 12 свойств. Достаточно запомнить **`display: flex` + `justify-content` + `align-items` + `flex-wrap`** — и вы закроете 90% задач вёрстки на начальном этапе. Остальные свойства смотрите по мере необходимости.
