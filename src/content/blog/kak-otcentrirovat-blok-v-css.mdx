Центрирование блока — **самая частая задача** в вёрстке. И самая болезненная для новичков. Раньше приходилось изобретать костыли с `position: absolute` и `transform`, сейчас есть **четыре нормальных способа**. Разберём каждый — с примерами, плюсами и минусами.

## Способ 1. Flexbox — рекомендуемый

Самый современный и универсальный способ. **Две строки CSS** — и блок отцентрирован.

```css
.container {
  display: flex;
  justify-content: center;  /* по горизонтали */
  align-items: center;      /* по вертикали */
  min-height: 100vh;        /* чтобы контейнер был во весь экран */
}
```

**HTML:**

```html
<div class="container">
  <div class="box">Я по центру</div>
</div>
```

**Что происходит:**

- **`display: flex`** — контейнер становится flex-контейнером
- **`justify-content: center`** — выравнивает детей по **главной оси** (по умолчанию — горизонталь)
- **`align-items: center`** — выравнивает по **поперечной оси** (по умолчанию — вертикаль)






**Плюсы:**

- **Работает везде** — все современные браузеры
- **Адаптивно** — не нужно знать размеры блока
- **Универсально** — можно центрировать несколько блоков сразу

**Минусы:**

- Не работает, если центрировать нужно **внутри `position: absolute`** родителя
- Если контейнер без высоты — вертикальное центрирование не сработает

**Когда использовать:** **99% случаев**. Это первый способ, о котором стоит думать.

## Способ 2. CSS Grid — ещё короче

Grid решает ту же задачу **в две строки** — но по другой логике.

```css
.container {
  display: grid;
  place-items: center;
  min-height: 100vh;
}
```

**Что происходит:**

- **`display: grid`** — контейнер становится grid-контейнером
- **`place-items: center`** — это сокращение для `align-items: center` + `justify-items: center`
- **`min-height: 100vh`** — растягивает контейнер на весь экран

**Плюсы:**

- **Самое короткое решение** — 2 строки
- **Работает без обёрток** — не нужно дополнительных контейнеров
- **Одинаково хорошо** для одного или нескольких блоков

**Минусы:**

- Если контейнер имеет **несколько строк сетки** — `place-items` применится ко всем ячейкам, а не к содержимому целиком

**Когда использовать:** когда контейнер **содержит один блок** и нужно быстро его отцентрировать.

## Способ 3. Position absolute + transform

Классический способ, работающий **даже без Flexbox и Grid**. Часто используется в модалках, попапах, оверлеях.

```css
.container {
  position: relative;
  min-height: 100vh;
}

.box {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

**Что происходит:**

- **`position: relative`** на родителе — создаёт точку отсчёта
- **`position: absolute`** на блоке — вырывает из потока
- **`top: 50%; left: 50%`** — верхний левый угол блока встаёт в **центр родителя**
- **`transform: translate(-50%, -50%)`** — сдвигает блок **на половину его собственных размеров** влево и вверх

**Плюсы:**

- Работает **во всех браузерах**, включая очень старые
- Не зависит от родителя — можно центрировать **относительно любого элемента**
- Идеально для **модалок и попапов**

**Минусы:**

- **Блок вырывается из потока** — другие элементы его не учитывают
- Нужно **знать родителя** — если родитель не `relative`, блок улетит относительно `body`

**Когда использовать:** когда Flexbox **недоступен** (например, внутри `position: absolute` родителя), или для модалок.

## Способ 4. Margin auto — только для горизонтали

Простой способ **горизонтального** центрирования, если у блока **фиксированная ширина**.

```css
.box {
  width: 400px;
  margin: 0 auto;
}
```

**Что происходит:**

- **`width: 400px`** — задаём фиксированную ширину
- **`margin: 0 auto`** — браузер автоматически распределяет **свободное место слева и справа**

**Плюсы:**

- **Самое простое решение** — одна строка
- Не нужен `display: flex` или `grid`
- Работает везде, включая старые браузеры

**Минусы:**

- **Не работает по вертикали** — `margin: auto` центрирует только по горизонтали
- **Нужна фиксированная ширина** — иначе `auto` не сработает
- Не подходит для адаптива, если блок должен тянуться

**Когда использовать:** когда нужно **только горизонтальное** центрирование и есть фиксированная ширина.

## Сравнение способов

| Способ | Горизонталь | Вертикаль | Строк CSS | Когда использовать |
|---|---|---|---|---|
| **Flexbox** | ✅ | ✅ | 3 | 99% случаев |
| **Grid** | ✅ | ✅ | 2 | Один блок, быстро |
| **position + transform** | ✅ | ✅ | 4 | Модалки, без Flexbox |
| **margin auto** | ✅ | ❌ | 1 | Только горизонталь |

## Частые ошибки новичков

**Ошибка 1: нет высоты у контейнера.** Если у `.container` нет `min-height`, вертикальное центрирование не сработает — блоку просто некуда центрироваться.

**Ошибка 2: путают `align-items` и `justify-content`.** В Flexbox:
- `justify-content` — **главная ось** (по умолчанию горизонталь)
- `align-items` — **поперечная ось** (по умолчанию вертикаль)

Если поменять `flex-direction: column` — **оси меняются местами**.

**Ошибка 3: забыли `transform` вместе с `top/left: 50%`.** Без `translate(-50%, -50%)` блок окажется **смещённым** — его верхний левый угол будет в центре, а не сам блок.

**Ошибка 4: `margin: auto` без `width`.** Если у блока нет фиксированной ширины, `auto` не сработает — он займёт всю доступную ширину.

## Итог

**Какой способ выбрать:**

- **Flexbox** — по умолчанию. Просто, надёжно, работает везде
- **Grid** — если хочется короче и один блок
- **Position + transform** — для модалок и когда Flexbox недоступен
- **Margin auto** — только для горизонтали и фиксированной ширины

**Правило для новичка:** если не знаете, какой способ использовать — берите **Flexbox**. Он закрывает 99% задач.
